🧠 Sección HEAD - Metadatos

El <head> contiene metadatos sobre la página que no se muestran directamente. Es crucial para SEO, rendimiento y funcionalidad.

Etiquetas Principales

<title>

Define el título de la página (aparece en la pestaña del navegador y resultados de búsqueda). Máximo 60 caracteres recomendado.

<meta charset>

Define el conjunto de caracteres. Siempre debe ser UTF-8 en la primera línea del head.

<meta name="viewport">

Configura el viewport para responsive design. Esencial para dispositivos móviles.

<meta name="description">

Descripción de la página para buscadores. 150-160 caracteres óptimos para SEO.

<link rel="stylesheet">

Carga archivos CSS externos. Siempre dentro del head.

<script>

Ejecuta código JavaScript. Si no es imprescindible cargarlo en head, suele colocarse al final del body o con atributos como defer.

Ejemplo Completo de HEAD

<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Descripción de 160 caracteres">
<title>Título de la Página - Máximo 60 caracteres</title>
<link rel="stylesheet" href="estilos.css">
</head>

Infografía: estructura básica del documento

  • <html> Raíz del documento
    • <head> Metadatos y recursos
      • <meta>Codificación y viewport
      • <title></title>Título de la página
      • <link>Hoja de estilos
      </head>
    • <body> Contenido visible
      • <header></header>Encabezado
      • <main></main>Contenido principal
      • <footer></footer>Cierre del documento
      </body>
    </html>
💡 SEO: El title y description son críticos para posicionamiento en buscadores. Hazlos descriptivos y con palabras clave relevantes.

📑 Headings - Vista General

La jerarquía de headings organiza el contenido de una página y ayuda a diferenciar el tema principal, las secciones y los niveles de detalle.

Qué debes recordar

  • H1 - Presenta el tema principal de la página
  • H2 - Divide el contenido en bloques grandes
  • H3-H6 - Descienden solo cuando el contenido lo necesita

Aplicación correcta

Una jerarquía ordenada facilita la lectura, mejora la comprensión del documento y ayuda a que los buscadores interpreten la estructura del contenido.

<h1>Tema principal</h1>
<h2>Bloque principal</h2>
<h3>Detalle del bloque</h3>
Jerarquía: Los headings organizan el contenido y ayudan a que la información sea comprensible para usuarios y buscadores.

📝 Etiquetas de Texto

Párrafos y Saltos de Línea

<p></p>

Define un párrafo. Siempre usa <p> para texto, nunca <br> múltiples veces.

<br>

Salto de línea. Self-closing. Usa con moderación.

<hr>

Línea horizontal. Indica cambio de tema.

Énfasis y Formato

Etiquetas Semánticas

<strong>Texto importante</strong>
<em>Texto énfasis</em>
<mark>Texto resaltado</mark>
<small>Texto pequeño</small>

Ejemplo Visual

Texto importante (negrita semántica)

Texto con énfasis (cursiva semántica)

Texto resaltado (highlight)

Texto pequeño (tamaño reducido)

Otras Etiquetas de Texto

  • <code> - Para código en línea
  • <pre> - Texto preformateado (preserva espacios)
  • <blockquote> - Cita larga
  • <q> - Cita corta
  • <abbr> - Abreviación
  • <address> - Información de contacto
💡 Consejo: Usa <strong> y <em> en lugar de <b> y <i> por mejor semántica.

🏗️ Semántica - Mapa del Sistema

La semántica organiza el significado de una página. Cada etiqueta indica qué función cumple un bloque dentro de la estructura general del documento.

<header> + <nav>

Presentan la identidad y orientan al usuario.

<main> + <section>

Contienen el contenido principal y sus bloques temáticos.

<article> + <aside>

Diferencian contenido autónomo y contenido de apoyo.

<figure> + <figcaption>

Añaden contexto a piezas visuales o técnicas importantes.

Semántica: Elegir la etiqueta adecuada mejora la claridad del documento, la accesibilidad y el mantenimiento del código.

🔽 Details y Summary

Crea contenido expandible/colapsable sin JavaScript.

Estructura

<p>Este contenido se muestra al expandir</p>

Ejemplo Interactivo

¿Qué son las etiquetas semánticas?

Las etiquetas semánticas son elementos HTML que dan significado al contenido. Comunican la intención del contenido tanto a navegadores como a dispositivos de asistencia. Ejemplos: <header>, <nav>, <main>, <article>, <section>, <footer>.

¿Cuál es la ventaja sobre div?

Los <div> son genéricos y no comunican significado. Las etiquetas semánticas indican el propósito: <nav> es explícitamente navegación, <header> es encabezado. Mejora SEO, accesibilidad y mantenibilidad del código.

¿Puedo tener múltiples details?

Sí, pero por defecto todos se abren independientemente. Si quieres que solo uno esté abierto a la vez, necesitas JavaScript. Usa <details name="grupo"> para agruparlos (soporte limitado en navegadores).

💡 Uso: Perfecto para FAQ, términos y condiciones, especificaciones técnicas, y contenido que no necesita verse inmediatamente.

📋 Formularios HTML

Estructura Básica

<form action="/enviar" method="POST">
<label for="nombre">Nombre:</label>
<input type="text" id="nombre" name="nombre" required>
<br>
<label for="email">Email:</label>
<input type="email" id="email" name="email" required>
<br>
<button type="submit">Enviar</button>
</form>

Tipos de Input Comunes

  • type="text" - Texto simple
  • type="email" - Validación email
  • type="password" - Texto oculto
  • type="number" - Solo números
  • type="date" - Selector de fecha
  • type="checkbox" - Casillas múltiples
  • type="radio" - Opción única
  • type="file" - Carga de archivos
  • type="submit" - Enviar formulario
  • type="button" - Botón personalizado

Elementos de Formulario

  • <label> - Etiqueta asociada a input. Mejora accesibilidad.
  • <textarea> - Texto multilínea
  • <select> - Lista desplegable
  • <option> - Opción en select
  • <fieldset> - Agrupa campos relacionados
  • <legend> - Título del fieldset
♿ Accesibilidad: Siempre usa <label> con atributo "for" que coincida con el id del input. Mejora la experiencia para usuarios con discapacidades.

📈 Tablas

Estructura Correcta de Tabla

<table>
<thead>
<tr>
<th>Encabezado 1</th>
<th>Encabezado 2</th>
</tr>
</thead>
<tbody>
<tr>
<td>Dato 1</td>
<td>Dato 2</td>
</tr>
</tbody>
</table>

Elementos de Tabla

  • <table> - Contenedor de la tabla
  • <thead> - Encabezados (para lectura de pantalla)
  • <tbody> - Datos principales
  • <tfoot> - Pie de tabla (totales, etc)
  • <tr> - Fila
  • <th> - Celda de encabezado
  • <td> - Celda de dato
♿ Accesibilidad: Usa <thead>, <tbody>, <th> correctamente. Las lectoras de pantalla las necesitan para entender la tabla.

⚙️ Atributos Globales

Estos atributos funcionan en prácticamente todas las etiquetas HTML.

  • id - Identificador único
  • class - Clase(s) CSS
  • style - Estilos inline
  • title - Tooltip al pasar ratón
  • data-* - Datos personalizados
  • hidden - Oculta elemento
  • tabindex - Orden de navegación
  • aria-* - Accesibilidad (ARIA)
  • contenteditable - Editable por usuario
  • draggable - Permite arrastrar

Ejemplos

<div id="main" class="container"
title="Contenedor principal"
data-version="1.0">
</div>

🚀 Desafíos Finales

1️⃣ Desafío: Estructura Completa

Crea una página HTML completa con head, meta tags, body y etiquetas semánticas

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Descripción">
  <title>Mi Página</title>
</head>
<body>
  <header>
    <nav>...</nav>
  </header>
  <main>
    <article>
      <h1>Título</h1>
      <p>Contenido</p>
    </article>
  </main>
  <footer>...</footer>
</body>
</html>

2️⃣ Desafío: Recorrido de estudio

Define un orden lógico de construcción para una página HTML completa, desde la estructura general hasta sus elementos específicos.

1. Define la estructura general del documento.
2. Organiza los headings según la jerarquía del contenido.
3. Añade texto, listas, tablas y formularios según la necesidad del documento.
4. Incorpora imágenes o elementos multimedia cuando aporten información relevante.

3️⃣ Desafío: Texto con Semántica

Usa <strong>, <em>, <mark> correctamente

<p>Este es un texto <strong>muy importante</strong> que <em>enfatizo</em> y <mark>resalto</mark>.</p>

4️⃣ Desafío: Formulario Completo

Crea un formulario con label, input, textarea, select, y button

<form action="/enviar" method="POST">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre" required>
  <br>
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>
  <br>
  <label for="mensaje">Mensaje:</label>
  <textarea id="mensaje" name="mensaje"></textarea>
  <br>
  <button type="submit">Enviar</button>
</form>

5️⃣ Desafío: Integración final

Combina estructura, texto y formularios en una sola página manteniendo una jerarquía clara y un marcado semántico correcto.

<main>
  <article>
    <h1>Guia de producto</h1>
    <section>
      <h2>Descripcion</h2>
      <p>Texto principal...</p>
    </section>
    <section>
      <h2>Contacto</h2>
      <form>...</form>
    </section>
  </article>
</main>

6️⃣ Desafío: Details y Semántica

Combina <details>, <summary>, <article>, <section>

<article>
  <h2>Mi Artículo</h2>
  <section>
    <h3>Primera Sección</h3>
    <p>Contenido...</p>
    <details>
      <summary>Más información</summary>
      <p>Contenido expandible...</p>
    </details>
  </section>
</article>
