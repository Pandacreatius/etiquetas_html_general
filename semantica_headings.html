Repaso: Semántica HTML5 & Headings

🏗️ ¿Qué es la Semántica HTML?

La semántica HTML refiere al significado de las etiquetas. Usar etiquetas semánticas significa elegir elementos que describan correctamente el contenido que envuelven.

Cuando utilizas <header> en lugar de <div class="header">, estás diciéndole a los navegadores, motores de búsqueda y dispositivos de asistencia que ese contenido es un encabezado.

¿Por qué es importante?

  • SEO: Los buscadores entienden mejor la estructura
  • Accesibilidad: Lectores de pantalla interpretan correctamente
  • Mantenimiento: El código es más legible y fácil de mantener
  • Estándares: Cumples con los estándares web HTML5
💡 Recuerda: La semántica no es sobre CSS o apariencia visual. Es sobre el significado y la estructura del contenido.

Principales Etiquetas Semánticas

<header>

Encabezado de la página o sección. Contiene logo, título, navegación introductoria.

<nav>

Navegación. Links a secciones principales de la página o sitio.

<main>

Contenido principal. Debe haber UNO por página. Contiene lo importante.

<article>

Contenido independiente. Blog post, noticia, resumen de producto.

<section>

Agrupa contenido temático. Generalmente tiene un heading (h2, h3, etc).

<aside>

Contenido tangencialmente relacionado. Sidebar, anuncios, información adicional.

<footer>

Pie de página. Derechos, links importantes, contacto, información legal.

<figure> y <figcaption>

Contenido ilustrativo con descripción. Imágenes, diagramas, código con contexto.

📑 Headings - H1 a H6

Los headings (encabezados) crean la estructura jerárquica del contenido. Cada nivel tiene un propósito específico.

Reglas Importantes

✅ UN H1 por página

El H1 es el título principal de la página. Debe ser único y descriptivo. Resume el tema principal de toda la página.

✅ Orden jerárquico

Después de H1, usa H2 para secciones principales. Dentro de H2, usa H3 para subsecciones. No saltes niveles (no hagas H1 → H3).

✅ Uno por sección

Cada sección <section> debe tener un único heading de su nivel apropiado (generalmente H2 o H3).

⚠️ Antipatrón: NO uses headings para styling (para hacer texto grande). Usa CSS. Los headings son para estructura semántica.

Jerarquía Visual

Estructura correcta

<h1>Tema Principal (Gran Título)</h1> <h2>Sección 1</h2> <p>Contenido...</p> <h3>Subsección 1.1</h3> <p>Contenido...</p> <h2>Sección 2</h2> <p>Contenido...</p> <h3>Subsección 2.1</h3> <p>Contenido...</p>

Diferencia entre niveles

Ejemplo visual de headings

H1 - Título Principal

H2 - Sección Principal

H3 - Subsección

H4 - Detalle

H5 - Detalle Menor
H6 - Detalle Muy Menor

🏛️ Estructura Completa de una Página

Esta es la estructura estándar y recomendada para todas las páginas HTML5:

Patrón: Header → Nav → Main → Footer

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <meta name="description" content="..."> <title>Título de la Página</title> </head> <body> <header> <p>Titulo del Sitio</p> <nav> <a href="#">Link 1</a> <a href="#">Link 2</a> </nav> </header> <main> <h1>Título principal de la página</h1> <article> <h2>Título del Artículo</h2> <section> <h2>Sección 1</h2> <p>Contenido...</p> </section> <section> <h2>Sección 2</h2> <p>Contenido...</p> </section> </article> <aside> <h3>Información Adicional</h3> <p>...</p> </aside> </main> <footer> <p>© 2024 Mi Sitio. Todos los derechos reservados.</p> </footer> </body> </html>

🎯 Estándar de Industria: Esta estructura (Header > Nav > Main > Footer) es el patrón utilizado por casi todos los sitios web modernos.

🖼️ Figure y Contexto Visual

Cuando una imagen necesita contexto dentro del contenido, se acompaña con <figure> y <figcaption> para expresar mejor su significado.

Cuándo usar figure

  • Cuando la imagen aporta información y no solo decoración
  • Cuando el recurso necesita explicación o referencia
  • Cuando quieres conectar una visual con una descripción legible

Patrón recomendado

<figure> <img src="diagrama.jpg" alt="Diagrama de la arquitectura"> <figcaption>Diagrama de arquitectura del sistema</figcaption> </figure>

Ejemplo Práctico

Qué dejamos para la guía de imágenes

  • alt, width, height y loading se desarrollan en la página dedicada a imágenes
  • Aquí lo importante es entender el papel estructural de la imagen dentro del contenido
Contexto visual: <figure> y <figcaption> aportan significado cuando una imagen necesita explicación dentro del contenido.

🚀 Desafíos Prácticos

1️⃣ Desafío: Estructura Básica

Crea una página HTML5 con estructura correcta: header, nav, main, article, sections y footer

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mi Página</title> </head> <body> <header> <p>Bienvenido</p> <nav><a href="#">Home</a></nav> </header> <main> <h1>Tema principal de la página</h1> <article> <h2>Mi Artículo</h2> <section> <h2>Primera Sección</h2> <p>Contenido...</p> </section> </article> </main> <footer><p>© 2024</p></footer> </body> </html>

2️⃣ Desafío: Headings Jerárquicos

Estructura correcta de headings: H1 único, H2 para secciones, H3 para subsecciones

<h1>Tema Principal de la Página</h1> <section> <h2>Primera Sección</h2> <p>Contenido principal de sección 1...</p> <h3>Subsección 1.1</h3> <p>Contenido de subsección...</p> </section> <section> <h2>Segunda Sección</h2> <p>Contenido principal de sección 2...</p> </section>

3️⃣ Desafío: Article con Sections

Artículo con estructura clara: título, múltiples secciones temáticas, imágenes

<article> <h1>Las Mejores Prácticas en HTML5</h1> <section> <h2>Introducción</h2> <p>HTML5 es el estándar actual...</p> <figure> <img src="img1.jpg" alt="Logo HTML5"> <figcaption>El logo oficial de HTML5</figcaption> </figure> </section> <section> <h2>Mejores Prácticas</h2> <p>Siempre usa etiquetas semánticas...</p> </section> </article>

4️⃣ Desafío: Página Completa

Página completa con header/nav/main/article/aside/footer. Estructura perfecta.

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Blog de Tecnología</title> </head> <body> <header> <p>Mi Blog Tech</p> <nav> <a href="/">Inicio</a> <a href="/blog">Blog</a> <a href="/contacto">Contacto</a> </nav> </header> <main> <h1>Tema principal de la página</h1> <article> <h2>Introducción a HTML5</h2> <section> <h2>¿Qué es HTML5?</h2> <p>HTML5 es...</p> </section> <section> <h2>Ventajas Principales</h2> <p>Las ventajas incluyen...</p> </section> </article> <aside> <h3>Artículos Relacionados</h3> <p>Links a artículos...</p> </aside> </main> <footer> <p>© 2024 Mi Blog Tech. Todos derechos reservados.</p> </footer> </body> </html>

5️⃣ Desafío: Figure y Figcaption

Usa figure correctamente para imágenes con contexto importante

<figure> <img src="arquitectura.png" alt="Diagrama de arquitectura del sistema" width="800" height="400"> <figcaption> Figura 1: Arquitectura de la aplicación web. El diagrama muestra la relación entre cliente, servidor y base de datos. </figcaption> </figure>

✅ Checklist Final - Dominas Semántica HTML

✔️ Entiendes por qué la semántica es importante (SEO, accesibilidad, mantenimiento)

✔️ Usas <header>, <nav>, <main>, <article>, <section>, <aside>, <footer> correctamente

✔️ Estructuras headings correctamente: UN H1, jerarquía lógica

✔️ Organizas páginas completas: Header → Nav → Main → Footer

✔️ Utilizas <figure> y <figcaption> para imágenes contextuales

✔️ Escribes atributo alt descriptivo en todas las imágenes

✔️ Usas <section> para agrupar contenido temático

✔️ Creas estructuras nidas y lógicas (sections dentro de articles)
