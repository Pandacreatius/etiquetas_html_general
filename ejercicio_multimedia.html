🔊 Audio - Sintaxis Básica

<audio controls>
<source src="cancion.mp3" type="audio/mpeg">
Tu navegador no soporta audio HTML5
</audio>

La etiqueta <audio> permite incrustar contenido de audio. Es importante proporcionar múltiples formatos para compatibilidad.

Atributos Principales

  • controls - Muestra botones de reproducción
  • autoplay - Reproduce automáticamente (requiere muted)
  • muted - Audio silenciado (necesario para autoplay)
  • loop - Repite la reproducción
  • preload - auto, metadata, none
💡 Importante: Los navegadores modernos bloquean autoplay sin muted. Siempre proporciona múltiples formatos con <source>

Formatos de Audio

  • MP3 - .mp3 | type="audio/mpeg" (más compatible)
  • WAV - .wav | type="audio/wav" (sin compresión)
  • OGG - .ogg | type="audio/ogg" (open source)
  • AAC - .aac | type="audio/aac" (calidad)
⚡ Consejo: Usa MP3 como primario y OGG como fallback para máxima compatibilidad

Atributos Avanzados

  • volume - Volumen de 0.0 a 1.0 (requiere JS)
  • currentTime - Posición actual (requiere JS)
  • duration - Duración total (requiere JS)
  • playbackRate - Velocidad de reproducción (requiere JS)

📋 Ejemplos

1️⃣ Audio Simple

Audio básico con controles

<audio controls>
<source src="musica.mp3"
type="audio/mpeg">
</audio>

2️⃣ Audio con Fallback

<audio controls preload="metadata">
<source src="audio.mp3" type="audio/mpeg">
<source src="audio.ogg" type="audio/ogg">
<p>Descarga: <a href="audio.mp3">MP3</a></p>
</audio>

3️⃣ Audio en Loop

<audio controls loop muted autoplay>
<source src="fondo.mp3">
</audio>

4️⃣ Audio con JavaScript

<audio id="miAudio">
<source src="cancion.mp3">
</audio>
<br>
<script>
const audio = document.getElementById('miAudio');
audio.volume = 0.5; // 50% volumen
audio.playbackRate = 1.5; // Reproducción 1.5x
</script>

🚀 Desafíos

1️⃣ Desafío Básico

Crea un audio con controles y preload en metadata

<audio controls preload="metadata">
  <source src="audio.mp3" type="audio/mpeg">
</audio>

2️⃣ Desafío Múltiples Formatos

Audio con MP3, OGG y WAV como fallback

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
  <source src="audio.wav" type="audio/wav">
</audio>

3️⃣ Desafío Avanzado

Audio en loop, muted y autoplay

<audio autoplay muted loop>
  <source src="fondo.mp3" type="audio/mpeg">
</audio>

✅ Checklist Audio

✔️ Usa múltiples formatos
✔️ Incluye atributo controls
✔️ Para autoplay, usa muted
✔️ Optimiza tamaño de archivo
✔️ Proporciona fallback de descarga

🎥 Video - Sintaxis Básica

<video controls width="640" height="360">
<source src="video.mp4" type="video/mp4">
Tu navegador no soporta video HTML5
</video>

La etiqueta <video> es similar a audio pero para contenido visual. Permite control total de reproducción y apariencia.

Atributos Principales

  • controls - Barra de control visible
  • width / height - Dimensiones del video
  • autoplay - Inicia automáticamente
  • muted - Necesario para autoplay
  • poster - Imagen antes de reproducir
  • preload - auto, metadata, none
💡 Tip: Usa poster para mostrar una imagen atractiva antes de que el usuario pulse play

Formatos de Video

  • MP4 - .mp4 | type="video/mp4" (estándar)
  • WebM - .webm | type="video/webm" (open source)
  • Ogg - .ogv | type="video/ogg" (alternativa)
📊 Compatibilidad: MP4 es el más universal. WebM para navegadores modernos

Atributos Video Específicos

  • playsinline - Reproduce en línea (no fullscreen en iOS)
  • crossorigin - Para CORS en videos remotos
  • controlsList - Controla qué botones mostrar

📋 Ejemplos

1️⃣ Video Simple

Video básico con controles

<video controls width="640" height="360">
<source src="video.mp4" type="video/mp4">
</video>

2️⃣ Video Responsive

<video controls width="100%" style="max-width: 800px">
<source src="video.mp4" type="video/mp4">
</video>

3️⃣ Video con Poster

<video controls width="640" height="360"
poster="portada.jpg">
<source src="video.mp4" type="video/mp4">
</video>

4️⃣ Video Múltiples Formatos

<video controls poster="cover.jpg"
playsinline>
<source src="video.mp4" type="video/mp4">
<source src="video.webm" type="video/webm">
<p>Descarga: <a href="video.mp4">MP4</a></p>
</video>

5️⃣ Video Autoplay

<video autoplay muted loop
width="100%">
<source src="fondo.mp4" type="video/mp4">
</video>

🚀 Desafíos

1️⃣ Desafío Básico

Video con poster y dimensiones fijas

<video controls width="640" height="360"
      poster="preview.jpg">
  <source src="video.mp4" type="video/mp4">
</video>

2️⃣ Desafío Responsive

Video que se adapta al ancho (max 800px)

<video controls playsinline
      width="100%"
      style="max-width: 800px;">
  <source src="video.mp4" type="video/mp4">
</video>

3️⃣ Desafío Múltiples Formatos

Video con MP4, WebM y fallback de descarga

<video controls poster="cover.jpg">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  <p>Descarga <a href="video.mp4">aquí</a></p>
</video>

4️⃣ Desafío Fondo

Video en loop muted sin controles como fondo

<video autoplay muted loop
      width="100%" height="100%">
  <source src="fondo.mp4" type="video/mp4">
</video>

✅ Checklist Video

✔️ Usa MP4 + WebM
✔️ Añade poster atractivo
✔️ Responsive con max-width
✔️ Para autoplay: muted + loop
✔️ Optimiza resolución (720p es buena)

🔗 iFrame - Sintaxis Básica

<iframe src="https://ejemplo.com"
width="640" height="360">
</iframe>

La etiqueta <iframe> (inline frame) permite incrustar contenido de otra página web dentro de la tuya. Es muy utilizada para mapas, vídeos, redes sociales, etc.

Atributos Principales

  • src - URL del contenido a incrustar
  • width / height - Dimensiones
  • style="border:0" - Forma moderna de quitar el borde visual si hace falta
  • allow - Permisos (fullscreen, camera, etc)
  • sandbox - Restricciones de seguridad
🔒 Seguridad: Usa sandbox para limitar qué acciones puede realizar el contenido embebido dentro del iframe.

Atributos de Seguridad

El atributo sandbox crea un entorno más aislado para el iframe. Cuando lo añades, el navegador aplica restricciones por defecto al contenido embebido: evita que ejecute ciertas acciones peligrosas, limita la interacción con la página principal y reduce el riesgo si el contenido externo no es totalmente confiable.

La idea general es esta: primero bloqueas todo lo que no necesitas y después vas permitiendo solo capacidades concretas mediante valores allow-.... Es una práctica muy útil cuando insertas contenido de terceros, formularios externos o páginas que no controlas directamente.

  • sandbox="" - Máxima restricción
  • sandbox="allow-same-origin" - Mantiene el origen original del documento, útil si el contenido necesita funcionar como misma procedencia
  • sandbox="allow-scripts" - Permite ejecutar JavaScript dentro del iframe
  • sandbox="allow-forms" - Permite enviar formularios desde el contenido embebido

Cómo interpretar sandbox

  • Sin sandbox - El iframe funciona con muchas más libertades, por lo que el contenido externo tiene menos restricciones.
  • Con sandbox vacío - El iframe queda muy bloqueado. Es la opción más segura si solo quieres mostrar contenido sin interacción compleja.
  • Con excepciones allow-... - Vas abriendo capacidades concretas solo cuando son necesarias para que ese recurso funcione bien.

Combinaciones habituales

Contenido visual simple

sandbox="" suele ser suficiente si solo quieres incrustar una página muy restringida y sin interacción avanzada.

Contenido con scripts

sandbox="allow-scripts" permite JavaScript, pero sigue manteniendo otras limitaciones de seguridad.

Formularios externos

sandbox="allow-forms allow-scripts" puede ser útil si el contenido necesita interacción y validaciones.

Casos más delicados

allow-same-origin debe usarse con criterio, porque da más libertad al documento embebido respecto a su origen.

⚠️ Importante: allow-same-origin no activa scripts por sí solo. Si necesitas scripts, debes indicar también allow-scripts. Cuantas menos excepciones añadas, más aislado estará el iframe.

Casos de Uso Comunes

  • YouTube - Embeber vídeos
  • Google Maps - Mapas interactivos
  • Spotify - Playlists/canciones
  • Twitter - Tweets embebidos
  • Páginas externas - Contenido completo

📋 Ejemplos

1️⃣ YouTube Responsive

Video de YouTube embebido

<iframe width="100%" height="315"
src="https://www.youtube.com/embed/ID"
allowfullscreen>
</iframe>

2️⃣ Google Maps

<iframe width="600" height="450" style="border:0"
src="https://www.google.com/maps/embed?..."
allowfullscreen="" loading="lazy">
</iframe>

3️⃣ Iframe Seguro

<iframe src="https://ejemplo.com"
width="100%" height="500"
sandbox="allow-same-origin allow-scripts"
title="Contenido embebido">
</iframe>

4️⃣ Documento Local

<iframe src="documento.html"
width="100%" height="600"
title="Página embebida">
</iframe>

5️⃣ Formulario Embebido

<iframe src="formulario.html"
sandbox="allow-same-origin allow-forms allow-scripts"
width="100%"
height="400">
</iframe>

🚀 Desafíos

1️⃣ Desafío YouTube

Embebe un video de YouTube responsivo (16:9)

<iframe width="100%" height="315"
      src="https://www.youtube.com/embed/VIDEO_ID"
      allowfullscreen>
</iframe>

2️⃣ Desafío Seguro

iFrame con sandbox para máxima seguridad

<iframe src="https://ejemplo.com"
      sandbox=""
      width="100%"
      height="500">
</iframe>

3️⃣ Desafío Formulario

iFrame que permite scripts y formularios

<iframe src="form.html"
      sandbox="allow-same-origin allow-scripts allow-forms"
      width="100%"
      height="400">
</iframe>

4️⃣ Desafío Completo

iFrame con todas las buenas prácticas

<iframe src="contenido.html"
      title="Contenido embebido"
      width="100%"
      height="600"
      style="border:0"
      loading="lazy"
      sandbox="allow-same-origin allow-scripts">
</iframe>

✅ Checklist iFrame

✔️ Usa sandbox cuando necesites aislar contenido embebido
✔️ Añade title para accesibilidad
✔️ Usa loading="lazy" para performance
✔️ Responsive: width="100%"
✔️ Valida URLs de origen confiable
