Sintaxis Atributos Responsive Ejemplos Desafíos

📚 Sintaxis Básica

<img src="imagen.jpg" alt="Descripción">

La etiqueta <img> es self-closing (no tiene etiqueta de cierre) y es el elemento fundamental para mostrar imágenes en web.

Atributos Obligatorios

  • src - Ruta o URL de la imagen (local o externa)
  • alt - Texto alternativo (accesibilidad y SEO)
💡 Tip: El atributo alt es crucial. Se muestra si la imagen no carga y ayuda a lectores de pantalla para personas con discapacidades visuales.

⚙️ Atributos Importantes

Dimensiones

  • width - Ancho en píxeles o porcentaje
  • height - Alto en píxeles o porcentaje
<img src="foto.jpg" width="300" height="200">

Comportamiento

  • loading="lazy" - Retrasa la carga de la imagen hasta que está cerca de entrar en pantalla. Reduce consumo inicial de datos y acelera la carga percibida de la página.
  • loading="eager" - Indica que la imagen debe cargarse cuanto antes. Es útil en imágenes visibles al abrir la página, como banners, portadas o recursos clave del primer bloque.
  • decoding="async" - Permite al navegador decodificar la imagen sin bloquear otras tareas de renderizado. Ayuda a que la interfaz siga respondiendo mientras la imagen se prepara.

SEO y Metadatos

  • title - Información al pasar el ratón
⚡ Performance: Usa loading="lazy" para imágenes debajo del fold (que no se ven inicialmente).

🎨 Responsive Images

srcset - Múltiples Resoluciones

<img src="imagen.jpg" srcset="imagen-small.jpg 480w, imagen-medium.jpg 768w, imagen-large.jpg 1200w" sizes="(max-width: 480px) 100vw, (max-width: 768px) 80vw, 60vw">

El navegador elige la imagen más adecuada según:

  • Ancho de la pantalla del dispositivo
  • Densidad de píxeles (Retina, etc.)
  • Velocidad de conexión
📱 Responsive: srcset es esencial para experiencias mobile optimizadas.

📋 Ejemplos Prácticos

1️⃣ Imagen Simple

Imagen responsive con alt descriptivo

<img src="imagen.jpg" alt="Descripción clara">

2️⃣ Imagen con Dimensiones Fijas

Tamaño fijo: 150x150

<img src="avatar.jpg" width="150" height="150" alt="Avatar del usuario">

3️⃣ Lazy Loading

<img src="imagen-pesada.jpg" alt="Contenido debajo del fold" loading="lazy">

4️⃣ Picture para Máximo Control

<picture> <source media="(max-width: 600px)" srcset="imagen-mobile.jpg"> <source media="(max-width: 1200px)" srcset="imagen-tablet.jpg"> <img src="imagen-desktop.jpg" alt="Contenido adaptativo"> </picture>
🎯 Uso: <picture> es ideal cuando necesitas cambiar completamente la imagen, no solo escalarla.

🚀 Desafíos

1️⃣ Desafío Básico

Crea una imagen con:

  • Ancho: 250px
  • Alt descriptivo
  • Título flotante
<img src="foto.jpg" width="250" alt="Mi foto bonita" title="Pasa el ratón">

2️⃣ Desafío srcset

Añade srcset para 3 resoluciones (480px, 768px, 1200px)

<img src="img.jpg" alt="Responsive"
      srcset="img-480.jpg 480w,
                img-768.jpg 768w,
                img-1200.jpg 1200w">

3️⃣ Desafío Avanzado

Imagen lazy con sizes para mobile-first

<img src="imagen.jpg" alt="Contenido"
      loading="lazy"
      decoding="async"
      srcset="img-small.jpg 480w,
                img-large.jpg 1200w"
      sizes="(max-width: 768px) 100vw,
                60vw">

4️⃣ Desafío Picture

Usa <picture> para diferentes imágenes por dispositivo

<picture>
  <source media="(max-width: 480px)"
            srcset="mobile.jpg">
  <source media="(max-width: 768px)"
            srcset="tablet.jpg">
  <img src="desktop.jpg" alt="Imagen adaptativa">
</picture>

✅ Checklist de Buenas Prácticas

  • ✔️ Incluir siempre atributo alt descriptivo
  • ✔️ Optimizar tamaño de archivo antes de subir
  • ✔️ Usar formatos modernos (WebP con fallback)
  • ✔️ Implementar responsive images con srcset
  • ✔️ Lazy load para imágenes debajo del fold
  • ✔️ Especificar width/height para evitar layout shifts
  • ✔️ Probar en diferentes dispositivos
  • ✔️ Considerar aspect-ratio en CSS

🎓 Lo Más Importante

La etiqueta <img> es simple pero poderosa. Dominar sus atributos significa crear experiencias web más rápidas, accesibles y atractivas en cualquier dispositivo. ¡Practica los desafíos y serás un experto!
